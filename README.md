# CCXT

Open-source (MIT) crypto exchange trading library: one unified API over 100+ exchanges, in JS/TS, Python, PHP, C#, Go, Java and Rust. A library, not a hosted API; also ships a local stdio MCP server (`ccxt-mcp`) and a CLI.

- Docs: https://docs.ccxt.com
- Source: https://github.com/ccxt/ccxt
